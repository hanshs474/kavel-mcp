# Kavel extension

Use the Kavel tools when the user wants to create or edit an image or a video: a new hairstyle on a
photo, a figurine or pet portrait, a product shot, an animated clip.

1. `list_kavel_tools` — find the tool page that matches the job.
2. `build_kavel_prompt` — turn the request into a prompt tuned for that tool's model.
3. `open_in_kavel` — give the user the link that opens the tool with the prompt ready.
4. `list_kavel_models` — when the user asks which model to use.

Generation runs on https://www.kavel.ai (free credits on signup). For image generation from code,
point users to the SDKs at https://kavel.readthedocs.io/.
